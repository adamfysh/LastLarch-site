Chokepoint Dependency Model

How the model works: data sources, pipeline architecture, simulation logic, validation approach, and known limitations. Written for risk professionals who want to understand what is under the hood before a conversation.

Model version 0.1 (April 2026)

Model pipeline

The model runs in four sequential stages. Each stage produces a discrete output that feeds the next. All stages are reproducible from publicly available data sources.

01
Data ingestion
UN Comtrade bilateral trade flows by HS code. Port coordinates from NGA World Port Index. Chokepoint coordinates and parameters defined manually.
02
Route inference
Each (exporter, importer) pair is assigned to the best-matching maritime corridor using a 27-corridor lookup table. Unmatched flows are flagged separately.
03
Dependency matrix
231 country-chokepoint-commodity combinations produced. Each cell states the share of a country's seaborne imports of a given commodity that transits a given chokepoint.
04
Simulation
Given chokepoint, severity (0-100%), and duration (days), the model computes trade value at risk, voyages disrupted, and applicable relief mechanisms.

Data sources

Trade flows
UN Comtrade (comtradeplus.un.org) — annual bilateral import data for 2022 by HS commodity code. The public preview API returns up to 500 records per call. Current model uses 3,500 raw rows across 7 commodity codes after rate-limited sequential download.
Port coordinates
NGA World Port Index (Pub. 150) — 3,898 ports with latitude, longitude, country, and port type. Published by the US National Geospatial-Intelligence Agency. Public domain.
Chokepoints
Manually defined — 22 chokepoints with coordinates, type classification, detour distance (km), and capacity sensitivity score. Detour distances sourced from published shipping literature and validated against voyage planning references.
AIS validation
IMF PortWatch (portwatch.imf.org) — aggregated vessel transit counts derived from AIS data, published weekly at ~1,000 major ports. Used to validate route inference outputs against observed traffic distributions. EIA weekly tanker flow data used for energy-specific corridor validation.
Commodity prices
IEA/EIA reference prices — cargo value per voyage estimated from typical vessel class cargo volumes at 2022 average commodity prices. VLCC: 60M, Suezmax: 0M, Aframax: 6M, Capesize: 0M, Panamax/Container: 0-80M.

Route inference

UN Comtrade reports annual bilateral trade values by commodity. It does not record the maritime route taken. The route inference stage assigns each (exporter country ISO, importer country ISO) pair to one of 27 pre-defined maritime corridors using a lookup table.

Each corridor definition specifies: the list of exporter ISO codes it covers, the list of importer ISO codes, the vessel type, the approximate distance in kilometres, and the ordered list of chokepoints transited. Route assignment uses the first matching corridor. Flows with no matching corridor are flagged as unmatched and excluded from the dependency matrix.

Route inference assumes ships take the shortest realistic path under normal operating conditions. The uncertainty lives here, and it is explicitly documented.

Current model performance: 899 of 3,294 clean trade flow rows are matched to corridors (27.3% of rows), capturing 04B of 97B total trade value (89.6% value coverage). The gap between row coverage and value coverage reflects the concentration of large-value flows in well-defined corridors: crude oil between Gulf exporters and major importers is both high-value and geographically predictable.

The 2,395 unmatched rows are predominantly small bilateral flows in commodity classes where trade routes are more diffuse, or flows between country pairs not yet in the corridor definitions. Adding corridors iteratively closes this gap.

Key assumption
Shortest realistic route under normal conditions. Does not model historical routing deviations or carrier-specific preferences.
Rerouting logic
Each corridor has a detour_km field specifying the additional distance if the primary chokepoint is blocked. Zero detour = no alternative (Hormuz, Bosporus). Positive detour = Cape route or equivalent available.
Supplier substitution
Corridors flagged with supplier_substitution: true (e.g. GULF_TO_USA, GULF_TO_BRAZIL) indicate that the importing country can switch to alternative supply sources rather than rerouting the same vessel. Substitution lag of 30-45 days is assigned based on contract and infrastructure flexibility.

Simulation logic

The simulation takes three inputs: a chokepoint identifier, a severity percentage (0-100%), and a duration in days. It queries the dependency matrix and returns trade value at risk and voyages disrupted by country and commodity.

Core calculation
effective_severity = severity_pct / 100 * capacity_sensitivity
value_at_risk = exposed_value_usd * effective_severity * (duration_days / 365)
voyages_disrupted = total_voyages * effective_severity * (duration_days / 365)
Where exposed_value_usd is the annual trade value of the country-chokepoint-commodity row in the dependency matrix, and capacity_sensitivity is a 0-1 score specific to each chokepoint reflecting how quickly partial disruption becomes effective closure.

Capacity sensitivity reflects the physical and commercial characteristics of each chokepoint. Hormuz and Bosporus score 1.0 because any disruption is immediately total: there is no alternative route and insurers withdraw coverage rapidly. Nodal hubs like Singapore score 0.6 because they degrade gradually before becoming critical, and cargo can partially reroute to secondary ports.

Validation approach

The model's route inference outputs are validated against three independent aggregated AIS-derived datasets. Validation checks whether the model's predicted share of trade transiting each chokepoint is directionally consistent with observed vessel traffic distributions. It does not attempt to match the model to individual voyage records.

IMF PortWatch
Port call and transit counts
Weekly vessel call counts at approximately 1,000 major ports and chokepoint transit volumes, derived from AIS. Published freely via API. Validates total traffic distribution across chokepoints.
EIA tanker flow data
Energy-specific corridor flows
Weekly and monthly aggregated tanker flow data published by the US Energy Information Administration, covering Hormuz, Bab-el-Mandeb, Suez, and Malacca. Directly validates energy commodity corridor assignments.
UNCTAD shipping statistics
Annual chokepoint volumes
UNCTAD publishes annual statistics on container flows and bulk cargo through major chokepoints, derived from AIS aggregation. Used for annual cross-check of overall chokepoint share estimates.
Delta check routine
Automated divergence flagging
A comparison routine computes the difference between model-inferred chokepoint shares and observed benchmark shares. Flows diverging by more than a configurable threshold (default 15%) are flagged for review. This is a planned addition to the pipeline, not yet implemented.

The validation approach is deliberately described as directional rather than exact. The model uses 2022 annual trade data; AIS aggregates reflect current and near-current vessel patterns. Trade patterns shift over time. The validation layer demonstrates that the route inference logic is grounded in observed reality, not that it replicates AIS records.

Current capabilities

01
Single chokepoint simulation
Query any of 22 chokepoints at variable severity and duration. Returns country-level and commodity-level trade value at risk with rerouting and substitution flags.
API endpoint: /impact
02
Multi-chokepoint scenario
Simulate simultaneous disruptions at multiple chokepoints. Aggregates impact by country across all affected corridors, removing double-counting.
API endpoint: /scenario
03
Dependency matrix query
Retrieve raw dependency scores for any country, chokepoint, or commodity combination. The core analytical output for portfolio accumulation analysis.
API endpoint: /dependency
04
Commodity filtering
All simulations can be filtered to a single HS commodity class. Allows cargo-specific analysis: a crude oil underwriter and a container goods underwriter see different exposure profiles.
Parameter: commodity_code
05
Rerouting vs interruption distinction
Each result row is flagged: reroute possible (with detour days), supplier substitution possible (with lag days), or no alternative. This distinction drives policy wording and loss quantification implications.
Fields: reroute_possible, supplier_substitution
06
Voyage-level decomposition
Annual trade values are decomposed into estimated voyage counts using vessel class cargo values. Enables underwriters to think in terms of individual policy exposures, not just aggregate trade statistics.
Field: estimated_voyages_per_year

Known limitations and scope boundaries

These limitations are stated explicitly because the model is intended to support serious risk analysis. A buyer who understands where the model is uncertain is better positioned to use it appropriately than one who is not.

2022 base year. Trade flow data is from UN Comtrade 2022. Patterns have shifted since, particularly in energy flows following the 2022-2024 Russian sanctions and the 2023-2025 Red Sea disruption. The model measures structural exposure under 2022 patterns, not current live flows. This is explicitly the "structural exposure under current trade patterns" framing described in the briefing note.
500-row API limit. The UN Comtrade public preview API returns a maximum of 500 records per call. The model uses the top 500 flows by trade value for each commodity code. Smaller bilateral flows are systematically underrepresented. This is why value coverage (89.6%) substantially exceeds row coverage (27.3%).
Annual, not periodic. The model does not capture seasonal patterns in commodity flows, monthly variation in vessel traffic, or the timing distribution of voyages within a year. Duration-based calculations use a simple linear scaling (duration_days / 365) rather than seasonal adjustment.
Country-level, not vessel-level. The voyage decomposition produces estimated voyage counts from annual trade values divided by typical cargo values. It does not track individual vessels, flag states, or policy-specific cargo. Portfolio-level accumulation analysis requires mapping individual policies to corridor assignments, which is a data integration step the model does not perform.
Capacity sensitivity scores are calibrated, not measured. The 0-1 capacity sensitivity scores for each chokepoint are informed judgements calibrated against historical disruption events. They are defensible parameters, not statistical estimates. They can and should be adjusted in a commercial deployment to reflect a buyer's own view of chokepoint risk profiles.
Land-based and pipeline flows excluded. Comtrade does not distinguish mode of transport. Some bilateral flows in the dataset are primarily overland, pipeline, or short-sea routes that are not meaningfully exposed to open-ocean chokepoints. These are excluded where corridor assignment is ambiguous, but the exclusion is not exhaustive.
